# Hero Workspace (generic)

This project uses [Hero](https://github.com/hero-engine/hero) for spec-driven development.

## Available commands

Agents, commands, and skills are installed in `.ai/`. Use the MCP server (registered in `.mcp.json`) for programmatic access.

## Key workflow

1. `/design <feature>` — create a spec
2. `/deliver <spec>` — implement from spec
3. `/diagnose <bug>` — investigate and produce fix spec
